# OutStake Oracles And Integrations

## 文档目的

本文档只说明当前 upgradeable 产品真源里与 oracle 和外部 integration 相关的边界。

## 边界

本节为 `OutrunExchangeOracleAdapter` 的语义真源；其他文档（基础规则表、术语表、架构总览、implementation map）对该 adapter 的描述均为指针或摘要。

- `OutrunExchangeOracleAdapter` 仍是非 upgradeable helper
- adapter 经 `AggregatorInterface.latestRoundData()` 读取 feed（`answer` 与 `updatedAt` 取自同一 round），不使用 `latestAnswer()`
- oracle-backed SY upgradeable variants 通过 `exchangeRateOracle` storage 指向 oracle adapter
- `setExchangeRateOracle(address)` 是 owner-only
- adapter 自身做 raw answer 正性检查（非正 revert `InvalidOracleAnswer`）、round 完整性检查（`answeredInRound < roundId` 视为未应答转结价，revert `StaleOracleAnswer`）与 `maxStaleness` 新鲜度窗口校验（`updatedAt == 0`、`updatedAt > block.timestamp`（feed 时钟超前）或超窗均 fail-closed，revert `StaleOracleAnswer`；`maxStaleness` 为 mutable 存储，owner 经 `OutrunExchangeOracleAdapter.sol::setMaxStaleness` 运行期可调）及可选构造期 L2 sequencer 校验，并在归一化后校验结果非零（`ZeroNormalizedRate`）；不提供 heartbeat、deviation bounds、fallback 或多源聚合保证；5 个具名错误全集声明于 `IExchangeRateOracle.sol`，校验实现见 `OutrunExchangeOracleAdapter.sol::getExchangeRate` 与 `OutrunExchangeOracleAdapter.sol::_validateSequencer`
- 构造期边界：`OutrunExchangeOracleAdapter.sol::constructor` 预计算 `_rawScale = 10 ** rawDecimals`（fail-fast）；feed `decimals() >= 78` 时 `10 ** rawDecimals` 超出 uint256，构造 revert `Panic(0x11)`、此类 feed 不可绑定——属构造期裸算术 panic，不在上述具名运行期错误之列
- 运行期边界：`OutrunExchangeOracleAdapter.sol::getExchangeRate` 归一化 `uint256(answer) * 1e18 / _rawScale` 中 checked 乘法在 `answer > floor((2**256-1)/1e18) ≈1.1579e59` 时 `uint256(answer) * SYUtils.ONE` 超出 uint256，revert `Panic(0x11)` fail-closed——属运行期裸算术 panic，不在 `IExchangeRateOracle.sol` 5 个具名运行期错误之列，与构造期 `10 ** rawDecimals` Panic 同一分隔；常规 feed 域（`decimals ≤18` 且值域远低于该阈值）不触发，极值域行为由 `MockOracleWarnings.t.sol:test_ExtremeAnswerRevertsFailClosed` 钉死为接受的 fail-closed 终态
- 构造期边界：`OutrunExchangeOracleAdapter.sol::constructor` 签名为 `constructor(address _oracle, uint256 _maxStaleness, address _sequencerUptimeFeed, uint256 _sequencerGracePeriod)`；拒绝 `_oracle == address(0)`（revert `InvalidOracle`）与 `_maxStaleness == 0`（revert `InvalidStaleness`）；零值不代表关闭新鲜度检查——零窗口下任何 `updatedAt < block.timestamp` 的异步 feed 均判 stale，等同永久不可用，故 fail-fast 于构造期（构造后 `maxStaleness` 为 mutable 存储，owner 经 `OutrunExchangeOracleAdapter.sol::setMaxStaleness` 运行期可调：owner 于构造期以 `msg.sender` 捕获为 immutable、无转移路径（显式决策，治理层考量）；setter 仅 owner 可调，非 owner 调用 revert adapter 本地错误 `NotOwner`；值域 `0 < v <= MAX_STALENESS`（`MAX_STALENESS` 为 30 天链上上限常量），越界（0 或超上限）复用 revert `InvalidStaleness`；成功 emit `SetMaxStaleness(uint256 oldMaxStaleness, uint256 newMaxStaleness)`）；`InvalidOracle` 属构造期错误，`InvalidStaleness` 为构造期与运行期 `setMaxStaleness` 路径共用，二者均属 adapter 本地错误，不属 `IExchangeRateOracle.sol` 声明的 5 个具名运行期错误之列（与 `Panic(0x11)` 同一分隔；`NotOwner`/`SetMaxStaleness` 亦为 adapter 本地声明，同在该 5 错误全集之外）
- `maxStaleness` 定值原则（逐 feed 实测口径，不按 feed 文档标称 heartbeat 定值）：部署前对每个绑定 feed 以链上 round 历史实测节奏——经 `latestRoundData()` 定位当前 round 后逐轮 `getRoundData(uint80)` 回溯取间隔，`maxStaleness ≥ 2 × 实测节奏`，为 feed 节奏波动与告警响应留余量。feed 的实际心跳会在线降档且不另行公告——窗口按降档前节奏设定时，降档后健康 feed 会被判 stale、`OutrunExchangeOracleAdapter.sol::getExchangeRate` 持续 revert `StaleOracleAnswer`（fail-closed 停摆）——故部署时必须实测当时节奏并留档，部署后持续监控 round 节奏变化，降档即重估窗口；adapter 仍非 upgradeable，但 staleness 窗口为运行期可调——feed 心跳降档后 owner 直接调用 `OutrunExchangeOracleAdapter.sol::setMaxStaleness` 调宽窗口（owner-only，值域 `0 < v <= MAX_STALENESS`，`MAX_STALENESS` 为 30 天链上上限常量；无 timelock，治理层考量由 owner 显式决策），重部署 adapter 并经 `setExchangeRateOracle` 换指针仅适用于更换底层 feed 源本身，不再为调宽窗口所需。实测样本参照（以太坊主网）：stETH/ETH 聚合器 `0x86392dC19c0b719886221c78AB11eb8Cf5c52812`（wstETH/ETH 派生率的 Chainlink 底座，wstETH↔stETH 腿为链上实时换算数学）近 60 rounds 跨 58.4 天，58/59 个间隔精确 86400s（心跳 = 24h）、1 个间隔 8h（偏差驱动），样本内最大单轮偏差 0.11%——stETH/ETH 为本栈唯一绑定的 Chainlink 型 feed（wstETH oracle-backed 变体率源底座），其 ≈24h 实测节奏是 `maxStaleness` 48h 量级口径的唯一产品依据；USDC/USD `0x8fFfFfd4AfB6115b954Bd326cbe7B4BA576818f6` 自 2026-08-04 起 round 间隔 ≈23h（此前 ~1h，为 feed 在线降档的实证），样本跨度约 29 天，样本内最大单轮偏差 0.018%——USDC/USD 为 feed 在线降档现象的行业实证样本，非本栈绑定（本栈 USDC 敞口经 aUSDC 的 Aave 流动性指数与 PSM 储备 1:1 兑换，均零喂价），仅支撑部署实测与节奏监控原则
- L2 sequencer 校验语义（仅当构造期配置了非零 `sequencerUptimeFeed` 才启用）：① Chainlink uptime feed 编码方向与直觉相反——`answer == 0` 表示 sequencer 在线，非 0 表示宕机（revert `SequencerDown`）；② 恢复后须经过 `sequencerGracePeriod` 宽限期才采信 answer（revert `SequencerGracePeriodNotOver`）；③ `startedAt == 0`（恢复从未记录）与 `startedAt > block.timestamp`（feed 时钟超前）两类不可信状态与宽限期未过共用同一错误名，简化实现下部署排错无法仅凭错误名区分根因（如需区分可拆分错误）。校验逻辑实现于 `OutrunExchangeOracleAdapter.sol::_validateSequencer`。
- Position 侧速率读取（消费端）：`OutrunStakingPositionUpgradeable.sol::_currentExchangeRate` 为全链路唯一速率读取点，仅校验 `rate != 0`（`ZeroExchangeRate`），不设本地带宽；适配器层保 `maxStaleness`/`sequencer` 新鲜度可用性；oracle-backed SY 基类侧以锚点偏差熔断对喂价数值（单点跳变）做链上带界拦截（语义见下方锚点偏差熔断条目），带内缓变漂移（累计/持续漂移）的带宽监控仍由链下完成。名义余额族 1:1 适配器在该读取点上游入口另设 resident 背书对账守卫：守卫由 `SYBaseUpgradeable` 提供共享入口断言（`SYBaseUpgradeable.sol::_revertIfBackingBelowShares`，不足即 revert 共享 `InsufficientBacking(uint256 residentBacking, uint256 outstandingShares)`），守卫覆盖适配器（七成员显式枚举，含 slisBNB 与 asBNB）的 `exchangeRate` 入口均接入，要求适配器自持 yield-bearing-token 余额 ≥ 流通 SY `totalSupply`（fail-closed，随单一率读取点传导至 SP 全部换算路径；单位依据、适用范围与诚实边界见 `docs/spec/yield/yield-adapters.md`）。`docs/deployment.md`「SY 背书沦陷应急处置」为该守卫的操作端文档锚点。
- **关键级（v1 上调）：铸造侧率值完整性（喂价异常导致超铸）的链上守卫全集按族分形——oracle-fed 族为 oracle fail-closed 栈（适配器新鲜度栈 + SY 基类锚点偏差熔断），Sky L2 族为 PSM3-SSR 双源偏差守卫，position 层 `ZeroExchangeRate` 单点守卫族无关共享**。v1 无 LTV、无清算（`docs/spec/position/accounting.md` §5.1），SP 按面值（价值平价）铸出——汇率虚高时面值铸造即超铸；oracle-fed 族（oracle-backed SY 变体）由适配器侧正性 / round 完整性 / 新鲜度窗口 /（配置时）sequencer / 归一化非零校验守新鲜度与可用性，SY 基类侧锚点偏差熔断（下方条目）守喂价数值异常（单点跳变/操纵）的链上拦截；Sky L2 族（`OutrunL2StakedUsdsSYUpgradeable`，无 `exchangeRateOracle`、不经 adapter）率值由 `OutrunL2StakedUsdsSYUpgradeable.sol::exchangeRate` 内 PSM3-SSR 双源偏差守卫承担——SSR 镜像读数相对 PSM3 报价（`previewSwapExactIn`）偏离超 `maxDeviationBps`（默认 100）即 revert `RateDeviationExceeded`，fail-closed 冻结铸造面（双源均为 Sky 控制的外部依赖，owner 可经 `setMaxDeviationBps` / `setRateProvider` 调参换源，语义真源 `docs/spec/yield/yield-adapters.md`）；position 层加 `ZeroExchangeRate` 单点守卫——这一全集（oracle-fed 族栈 + Sky L2 族双源偏差守卫 + 零点守卫）是铸造侧率值维度的链上守卫（与 resident 背书对账守卫的余额维度互补，见本节『Position 侧速率读取（消费端）』条目）；带内缓变漂移与 owner 换源/调参信任残余仍属链下监控与 pause 联动职责（监控与应急见 `docs/deployment.md`）。`redeem` SY 直出不读率（owner 退出通道，oracle 无关）。
- 锚点偏差熔断（`OutrunL2OracleBackedSYUpgradeable` 基类）：oracle-backed L2 变体（`OutrunL2WstETHSYUpgradeable`、`OutrunL2StakedTokenSYUpgradeable`）经继承获得，对经 `exchangeRateOracle` 读回的 conversion rate 施加锚点带界的链上数值拦截（fail-closed）；主网 wstETH adapter（`OutrunWstETHSYUpgradeable`）与 Sky adapter（`OutrunL2StakedUsdsSYUpgradeable`）无 `exchangeRateOracle`，不在覆盖范围。存储与 `exchangeRateOracle` 同一 ERC-7201 namespace struct（`erc7201("outrun.storage.OutrunL2OracleBackedSY")`）追加字段：rate anchor（锚点）值、anchor timestamp 与三个熔断参数 `maxDropBps`（默认 10）、`riseBpsPerHour`（默认 5）、`maxRiseCapBps`（默认 200）。锚点生命周期：`OutrunL2OracleBackedSYUpgradeable.sol::__L2OracleBackedSY_init` 读一次 oracle 播种锚点（首个被接受的读数；读数为零即 init revert `ZeroRateAnchor()`，fail-fast）；`OutrunL2OracleBackedSYUpgradeable.sol::commitRateAnchor` 为 permissionless 外部入口——读当前 oracle rate 对已存锚点做带界检查，带内才推进 anchor 与 timestamp，带外 revert `RateDeviationExceeded`，成功 emit `RateAnchorCommitted(uint256 indexed anchor, uint256 timestamp)`；视图读不推进锚点（`OutrunL2OracleBackedSYUpgradeable.sol::exchangeRate` 保持 view）；`OutrunL2OracleBackedSYUpgradeable.sol::resetRateAnchor` 为 onlyOwner 恢复路径——无条件把锚点重同步为当前 oracle 读数（读数为零即 revert `ZeroRateAnchor()`，fail-fast——与 init 播种共享同一零读数错误面，无条件重置永不能播种 anchor==0 并静默停用带检查；合法 regime 变更后采纳，如换量级不同的 feed 源；owner 只能采纳 feed 当前返回值、不能注入任意值），emit `RateAnchorReset(uint256 indexed oldAnchor, uint256 indexed newAnchor)`。
- 锚点带界语义与入口错误面：被接受的读数须落在 `[anchor × (1e4 − maxDropBps)/1e4, anchor × (1e4 + min(riseBpsPerHour × elapsedSeconds / 3600, maxRiseCapBps))/1e4]`——下行侧无时间额度（staked 资产 conversion rate 单调不降，任何即时下跌均为异常），上行额度自锚点 timestamp 起按秒连续累计（`allowanceBps = min(riseBpsPerHour × elapsedSeconds / 3600, maxRiseCapBps)`）且封顶 `maxRiseCapBps`（keeper 停摆不把带宽放大超过 cap）；链上计算经单次末位除法、无 sub-bps 截断损耗（cap 施加于 bps·秒乘积项：`maxRate = anchor × (3600×1e4 + cappedSecondsTerm) / (3600×1e4)`，`cappedSecondsTerm = min(riseBpsPerHour × elapsedSeconds, maxRiseCapBps × 3600)`）。按秒连续累计取代整小时步进（旧式 `riseBpsPerHour × elapsedHours`）：整小时截断使 elapsed < 1h 时额度为 0、且任意 commit 重置 elapsed——攻击者每小时 commit 一次即可把锚点钉住，令自然上行的 feed（任何严格更高读数，哪怕 +1 wei）在满 1 小时前持续 revert `exchangeRate()`（约 1 tx/hour 的铸造面 griefing）；连续累计消除了旧行为的 +wei 级窗口，但 commit 重置 elapsed 仍有可用性代价：commit 后额度自新锚点归零重积，紧邻其后（或额度重积不足时）的 feed round 跳变 Δ bps 使 `exchangeRate()` 持续 revert `RateDeviationExceeded` 直至额度累计到 Δ——阻断窗 = Δ bps ÷ `riseBpsPerHour` 小时（现实量级：本栈唯一绑定 feed 样本内最大单轮偏差 11 bps ÷ 默认 5 bps/hour ≈ 2.2 小时，典型日漂移 0.85 bps 量级 ≈ 10 分钟）。Δ ≤ `maxRiseCapBps` 域窗口随时间自愈；Δ > `maxRiseCapBps` 域读数永不入带、带内 commit 不可能，唯一恢复为 owner 经 `OutrunL2OracleBackedSYUpgradeable.sol::resetRateAnchor` 重置锚点（`setRateBreakerParams` 放宽链上可行，但被部署 runbook 明文禁止作为替代）。窗口时序既可来自任意人的等读数 commit 钉锚（permissionless，每 round 一笔即可），也可来自 keeper 固定节奏 commit 恰落在跳变前——残余缺口见下一条目 (e)。诚实边界：整点之间连续带略宽于旧步进函数（线性 vs 每小时 0→5 bps 跳变），差值至多一小时额度、仍受 cap 封顶；下行侧不变，视图读仍不推进锚点。`OutrunL2OracleBackedSYUpgradeable.sol::exchangeRate` 外部形状不变，返回前对 oracle 读数做带界检查，带外 revert `RateDeviationExceeded(uint256 newRate, uint256 anchorRate, uint256 allowedBps)`——该错误经 `OutrunStakingPositionUpgradeable.sol::_currentExchangeRate` 原样透传（与 adapter staleness 错误同一 passthrough 通道），`stakeForGenesis` / `previewStake` fail-closed；`redeem` SY 直出不读率、不受影响（owner 退出通道语义不变）。该错误与 `OutrunL2StakedUsdsSYUpgradeable` 的同名错误为不同合约的独立声明（参数形态不同，见 `docs/spec/yield/yield-adapters.md` 错误面）。`OutrunL2OracleBackedSYUpgradeable.sol::setRateBreakerParams(uint16 maxDropBps, uint16 riseBpsPerHour, uint16 maxRiseCapBps)` 为 onlyOwner，逐参数 sanity 域 `1..10000`，越界 revert `InvalidRateBreakerParams()`，emit `SetRateBreakerParams(uint16 maxDropBps, uint16 riseBpsPerHour, uint16 maxRiseCapBps)`（保持全参数不加 indexed：三个 uint16 作为 topic 只增日志成本、无过滤价值）。锚点写入三入口 `OutrunL2OracleBackedSYUpgradeable.sol::__L2OracleBackedSY_init` / `OutrunL2OracleBackedSYUpgradeable.sol::commitRateAnchor` / `OutrunL2OracleBackedSYUpgradeable.sol::resetRateAnchor` 在把 oracle 读数窄化存入 uint96 rateAnchor 之前校验量级：读数超过 `type(uint96).max` 即先 revert `RateAnchorOverflow(uint256 reading)`（防御性边界——否则 2^96 整倍数读数窄化为 anchor == 0、经 anchor==0 防御性跳过静默停用带检查；1e18 量级 conversion rate 在 uint96 下仍有约 11 个数量级裕量）。`OutrunL2OracleBackedSYUpgradeable.sol::setExchangeRateOracle` 语义不变（instant、onlyOwner、emit `SetExchangeRateOracle(old, new)`、无 timelock——产品模型为 owner-only），唯一新增语义为保留已存锚点：换入的 oracle 仍须对旧锚点通过带界，owner 采纳量级合法不同的源走显式 `resetRateAnchor()`。
- 锚点偏差熔断阈值口径与诚实残余缺口：staking-APR 级资产日漂移 ≈0.85 bps/day（≈3% APR），默认值中 rise 侧携 ≥100× 余量——drop 10 bps 仅为噪声容限，rise 5 bps/h ≈ 真实漂移速度的 140×，cap 200 bps 为自最近一次锚点写入起的单窗口带宽上界 2%。部署校准程序（与 `maxStaleness` round 历史回测同法，运维落点见 `docs/deployment.md`「L2 oracle-backed SY 部署校验清单」）：经 `getRoundData` 回溯 feed 全 round 历史逐参数归一定值——`maxDropBps` 取 `max(3 × 观测到的最大相邻 round 下行跳变 bps, 默认 10)`、`riseBpsPerHour` 取 `max(3 × 观测到的最大相邻 round 跳变折算 bps/hour（跳变 bps ÷ round 间隔小时数）, 默认 5)`、`maxRiseCapBps` 仍为绝对上界的校准定值（默认 200）——均只上调不下调，样本留档。残余缺口（如实申报，不超卖）：(a) 带内缓升漂移仍放行，cap 只封界自最近一次锚点写入起的单窗口超铸（每次带内 `commitRateAnchor` 重定带基准：持续提交可使锚点按 `riseBpsPerHour`/hour 复利上旋、或按每次 `maxDropBps` 下旋，累计漂移无 cap；锚点永不超出真实 oracle 读数，跟踪腐化 feed 的累计漂移仅由单源 oracle 信任与监控约束——监控锚点推进速率（`RateAnchorCommitted` 节奏与幅度），不只盯带界）；(b) 锚点播种时刻起即错误的 feed 不被捕获（v1 无独立第二源）；(c) owner 信任残余——owner 可把 oracle 指向带内漂移的 feed、可 `resetRateAnchor()` 采纳当前读数，仅监控缓解（产品模型定为 owner-only）；(d) 熔断位于 SY 侧，adapter 的 staleness/sequencer 新鲜度校验不变且互补；(e) commit 时序可用性窗口——permissionless commit 可在读数==锚点时（带内恒可）清零 elapsed，使紧邻其后的合法 round 跳变产生上一条目量化的阻断窗；校准包络内每跳变周期占空比上界 1/3（校准式保证 `riseBpsPerHour` ≥ 3 × 观测最大跳变 ÷ round 间隔小时，故窗口 ≤ 间隔 ÷ 3），超出校准观测包络的跳变可突破该界；`RateAnchorCommitted` 节奏监控不能区分恶意等读数 commit 与 keeper 正常 commit（事件无 sender topic）、不能阻止或解除窗口，实际缓解为 owner 经 `OutrunL2OracleBackedSYUpgradeable.sol::resetRateAnchor` 即时恢复（redeem 退出通道不读率、无资金影响）；keeper 安全节奏为紧跟 round 更新后 commit（下次跳变时保有整间隔累计额度），固定时钟盲 commit 以自身节奏开窗。

## Evidence Rules

- Local unit tests prove only local adapter branching, arithmetic, token validation, pause, owner setter, and revert behavior.
- Fork tests prove only pinned-block interaction with configured upstream contracts.
- External protocol semantics require primary evidence: verified source, official upstream repository, official documentation, or reproducible fork trace.
- If no primary evidence exists for a behavior, it remains a trust boundary and must not be described as a local guarantee.

## 外部依赖边界

- `OutrunL2StakedUsdsSYUpgradeable` 的 `exchangeRate()` 率源为 `OutrunL2StakedUsdsSYUpgradeable.sol::initialize` 经 `IPSM3.rateProvider()` 绑定的 SSR RateProvider（外部依赖），PSM3 `previewSwapExactIn` 仅作 `maxDeviationBps` 偏差守卫引用（与 `docs/spec/yield/yield-adapters.md` Adapter Evidence Matrix 对齐）；quote、liquidity、token/governance config 均属外部依赖
- oracle-backed variants 只消费配置好的单一 oracle 输出；freshness 由 adapter 层提供（构造期定初值，运行期 owner 经 `OutrunExchangeOracleAdapter.sol::setMaxStaleness` 可调，上限 30 天），数值带界由 SY 基类锚点偏差熔断提供（语义见「边界」节）；仍不提供 fallback/多源聚合
- pinned fork evidence 必须固定 block；不得把 latest fork 结果写成本地保证或长期语义保证
